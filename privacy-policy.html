Politique de Confidentialité

Dernière mise à jour : 10 novembre 2025

📌 En résumé : Vos données restent sur votre appareil. Nous ne collectons, ne stockons et ne transmettons AUCUNE donnée personnelle à nos serveurs. Cependant, certains services tiers (CDNs) peuvent collecter votre adresse IP.

1. Qui sommes-nous ?

Business Tools est un projet open-source développé par Synoptia, offrant 100 outils web gratuits pour la gestion d'entreprise.

  • Éditeur : Synoptia
  • Contact : ludo@synoptia.fr
  • Site web : www.synoptia.fr

2. Quelles données personnelles traitons-nous ?

2.1. Données traitées localement (sur votre appareil)

Les outils Business Tools fonctionnent 100% en local dans votre navigateur. Les données suivantes sont stockées uniquement sur votre appareil via localStorage :

  • Factures et devis générés
  • Données de time tracking (temps de travail)
  • Configurations et préférences utilisateur
  • Historiques de calculs financiers
  • Données de gestion de projets (tâches Kanban, etc.)
  • Informations clients/fournisseurs que vous saisissez
⚠️ IMPORTANT : Ces données ne quittent JAMAIS votre appareil. Elles ne sont pas envoyées à nos serveurs ou à des tiers. Elles sont accessibles uniquement depuis votre navigateur.

2.2. Données collectées par des services tiers

Notre site utilise des services externes qui peuvent collecter des données :

a) Google Fonts

  • Données collectées : Adresse IP, User-Agent, Referer, Timestamp
  • Finalité : Chargement des polices de caractères
  • Destinataire : Google LLC (États-Unis)
  • Base légale : Intérêt légitime (amélioration de l'expérience utilisateur)
  • Conservation : Variable selon Google (consulter politique de confidentialité Google)
🚨 Note RGPD : L'utilisation de Google Fonts sans consentement préalable a été jugée non conforme au RGPD par plusieurs tribunaux européens (LG München I, 2022). Nous travaillons à auto-héberger les polices pour être pleinement conformes.

b) Cloudflare CDN (Font Awesome)

  • Données collectées : Adresse IP, User-Agent
  • Finalité : Diffusion des icônes Font Awesome
  • Destinataire : Cloudflare Inc. (États-Unis)
  • Base légale : Intérêt légitime

c) jsDelivr CDN (Chart.js, DOMPurify)

  • Données collectées : Adresse IP, User-Agent
  • Finalité : Diffusion des bibliothèques JavaScript
  • Destinataire : jsDelivr
  • Base légale : Intérêt légitime

3. Cookies et technologies similaires

Ce site n'utilise AUCUN cookie de tracking ou publicitaire.

Seul le localStorage du navigateur est utilisé pour sauvegarder vos données localement (factures, calculs, préférences). Vous pouvez effacer ces données à tout moment via les paramètres de votre navigateur.

4. Durée de conservation

  • Données localStorage : Conservées indéfiniment sur votre appareil jusqu'à ce que vous les supprimiez manuellement
  • Données CDNs tiers : Consultez les politiques de confidentialité respectives (Google, Cloudflare, jsDelivr)

5. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

5.1. Droit d'accès

Vous pouvez accéder à vos données en ouvrant les outils de développement de votre navigateur :

  • Chrome/Edge : F12 → Application → Local Storage
  • Firefox : F12 → Stockage → Stockage local
  • Safari : Développement → Afficher l'inspecteur Web → Stockage

5.2. Droit à l'effacement

Vous pouvez supprimer toutes vos données à tout moment :

  • Méthode 1 : Effacer les données de navigation de votre navigateur
  • Méthode 2 : Ouvrir la console (F12) et exécuter : localStorage.clear()
  • Méthode 3 : Utiliser le bouton "Effacer mes données" présent dans certains outils

5.3. Droit d'opposition

Pour vous opposer au chargement des ressources externes (Google Fonts, CDNs) :

  • Utilisez un bloqueur de contenu (uBlock Origin, AdBlock Plus)
  • Configurez votre navigateur pour bloquer les requêtes tierces
  • Utilisez le mode navigation privée

5.4. Droit de réclamation

Si vous estimez que vos droits ne sont pas respectés, vous pouvez déposer une réclamation auprès de :

  • CNIL (France) : www.cnil.fr
  • Votre autorité nationale de protection des données

6. Sécurité des données

Nous mettons en œuvre les mesures de sécurité suivantes :

  • ✅ Chiffrement HTTPS (connexion sécurisée)
  • ✅ SRI (Subresource Integrity) sur les CDNs pour éviter les injections de code
  • ✅ Sanitization des données utilisateur pour prévenir les attaques XSS
  • ✅ Pas de stockage côté serveur (données 100% locales)
  • ✅ Code source open-source et auditable : GitHub
⚠️ Données sensibles : Si vous utilisez nos outils pour stocker des données sensibles (mots de passe WiFi, informations financières), nous vous recommandons :
  • D'utiliser un appareil sécurisé
  • De ne pas partager votre appareil avec des tiers non autorisés
  • D'effacer régulièrement votre localStorage

7. Transferts hors UE

Les services tiers utilisés (Google, Cloudflare, jsDelivr) peuvent entraîner des transferts de données vers les États-Unis. Ces transferts sont effectués sur la base de :

  • Clauses contractuelles types approuvées par la Commission Européenne
  • Intérêt légitime pour l'amélioration de l'expérience utilisateur

8. Enfants

Nos services ne s'adressent pas spécifiquement aux mineurs. Nous ne collectons pas sciemment de données personnelles auprès de personnes de moins de 16 ans.
