Formules

Marge unitaire = Prix de vente - Coût variable unitaire Taux de marge = (Marge unitaire / Prix) × 100 Marge totale = Marge unitaire × Quantité Résultat net = Marge totale - Coûts fixes Seuil de rentabilité = Coûts fixes / Marge unitaire

Utilité

  • Décision de prix : Déterminez le prix minimum viable
  • Mix produits : Identifiez les produits les plus rentables
  • Seuil de rentabilité : Calculez le volume nécessaire pour être rentable
