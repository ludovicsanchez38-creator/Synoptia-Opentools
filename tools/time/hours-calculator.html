Comment utiliser ?

  1. Choisissez le mode de calcul (durée, addition ou soustraction)
  2. Mode Durée : Entrez l'heure de début, de fin et la pause
  3. Mode Addition : Ajoutez des heures à une heure de base
  4. Mode Soustraction : Retranchez des heures d'une heure de base
  5. Cliquez sur "Calculer" pour voir le résultat
  6. L'historique se sauvegarde automatiquement

Conseils

  • Format horaire : Utilisez le format 24h (17:30 et non 5:30 PM)
  • Format décimal : Utile pour la paie (8.5h = 8h30)
  • Pauses obligatoires : En France, 20 min obligatoires après 6h de travail
  • Limite journalière : 10h maximum par jour (loi française)
  • Export CSV : Pour archiver vos calculs ou importer dans Excel

Réglementation (France)

  • Durée maximale : 10h/jour (12h avec dérogations)
  • Pause obligatoire : 20 min après 6h de travail consécutif
  • Repos quotidien : 11h consécutives minimum
  • Heures supplémentaires : Au-delà de 35h/semaine
  • Majoration : +25% pour les 8 premières heures sup, +50% au-delà
