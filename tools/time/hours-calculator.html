Comment utiliser cet outil ?

  1. Saisissez votre heure de début
  2. Saisissez votre heure de fin
  3. Indiquez la durée de pause en minutes
  4. Optionnel : ajoutez votre taux horaire pour calculer la rémunération
  5. Cliquez sur "Calculer"

Conseils

  • Le format décimal est pratique pour les logiciels RH
  • L'historique est sauvegardé automatiquement
  • Utilisez le taux horaire pour estimer vos revenus
