Comment utiliser ?

  1. Ajoutez vos projets avec le bouton "Ajouter un projet"
  2. Entrez vos heures pour chaque jour (format décimal : 7.5 pour 7h30)
  3. Les totaux se calculent automatiquement
  4. Naviguez entre les semaines avec les flèches
  5. Sauvegardez ou exportez en CSV pour archivage

Conseils

  • Format heures : Utilisez le format décimal (8.5 = 8h30, 7.75 = 7h45)
  • Sauvegarde auto : Vos données sont sauvegardées dans le navigateur
  • Semaine type : 35-40h pour un temps plein
  • Export régulier : Exportez chaque fin de mois pour facturation/paie

Durée légale du travail (France)

  • Hebdomadaire : 35h (temps plein), 39h avec heures sup
  • Journalier : 10h maximum (sauf dérogations)
  • Heures sup : Au-delà de 35h/semaine (+25% ou +50%)
