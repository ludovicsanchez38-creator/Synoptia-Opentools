Comment utiliser cet outil ?

  1. Sélectionnez la semaine de travail
  2. Ajoutez vos projets
  3. Saisissez les heures travaillées pour chaque jour
  4. Les totaux sont calculés automatiquement
  5. Exportez votre timesheet en CSV

Conseils

  • Saisissez vos heures quotidiennement pour plus de précision
  • Utilisez les codes projet pour faciliter le suivi
  • Le taux de remplissage est basé sur 40h/semaine
  • Double-cliquez sur une cellule pour la modifier
