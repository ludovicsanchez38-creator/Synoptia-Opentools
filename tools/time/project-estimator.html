Méthode PERT

La méthode PERT (Program Evaluation and Review Technique) utilise la formule :

Estimation = (Optimiste + 4×Probable + Pessimiste) / 6

Conseils

  • Optimiste : Tout se passe parfaitement
  • Probable : Scénario réaliste avec imprévus normaux
  • Pessimiste : Difficultés majeures
  • Ajoutez 20-30% de marge pour les imprévus
