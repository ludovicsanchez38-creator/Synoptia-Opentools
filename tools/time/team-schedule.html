Comment utiliser ?

  1. Ajoutez les membres de votre équipe
  2. Cliquez sur le bouton "+" dans une case pour ajouter un shift
  3. Renseignez l'heure de début, de fin et optionnellement un libellé
  4. Naviguez entre les semaines avec les flèches
  5. Les totaux se calculent automatiquement
  6. Exportez en CSV pour partager avec l'équipe

Conseils de planification

  • Anticiper : Planifiez 2-3 semaines à l'avance minimum
  • Équilibrer : Répartissez équitablement les heures entre membres
  • Pauses : Assurez 11h de repos entre 2 shifts pour un même membre
  • Communication : Partagez le planning au moins 7 jours à l'avance
  • Flexibilité : Gardez une marge pour les imprévus (absences, urgences)

Réglementation (France)

  • Durée maximale : 10h/jour, 48h/semaine (44h en moyenne sur 12 semaines)
  • Repos quotidien : 11h consécutives minimum
  • Repos hebdomadaire : 35h consécutives (24h + 11h de repos quotidien)
  • Délai de prévenance : 7 jours pour modification du planning
  • Temps partiel : Minimum 24h/semaine (sauf exceptions)
