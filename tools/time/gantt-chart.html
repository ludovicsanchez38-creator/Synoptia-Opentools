Guide d'utilisation

  • Ajouter une tâche : Cliquez sur "Nouvelle tâche" et définissez les dates
  • Statuts : À faire (gris), En cours (bleu), Terminé (vert)
  • Vue Gantt : Visualisez les tâches sur une timeline avec barres
  • Vue Liste : Affichez toutes les tâches sous forme de liste
  • Modifier : Cliquez sur une barre ou une tâche pour la modifier
