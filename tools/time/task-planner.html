Comment utiliser

  • Ajouter : Entrez le nom de votre tâche, sélectionnez la priorité et cliquez sur "Ajouter"
  • Compléter : Cochez la case pour marquer une tâche comme terminée
  • Filtrer : Utilisez les boutons de filtre pour afficher les tâches par statut ou priorité
  • Supprimer : Cliquez sur l'icône poubelle pour retirer une tâche
  • Priorités : Rouge = Haute, Orange = Moyenne, Vert = Basse
  • Export : Exportez vos tâches en CSV pour analyse externe
