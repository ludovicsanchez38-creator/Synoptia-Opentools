Comment utiliser cet outil ?

  1. Cliquez sur Nouvelle Tâche et remplissez les informations
  2. Définissez une date d'échéance et une priorité
  3. Utilisez les filtres pour voir différentes vues de vos tâches
  4. Cochez les tâches terminées ou modifiez-les selon l'avancement
  5. Exportez votre liste pour la sauvegarder ou la partager

Conseils

  • Priorité Haute (Rouge) : Tâches urgentes et importantes
  • Priorité Moyenne (Jaune) : Tâches importantes mais pas urgentes
  • Priorité Basse (Vert) : Tâches à faire quand vous avez du temps
  • Les tâches en retard sont surlignées en jaune
  • Toutes les données sont sauvegardées automatiquement dans votre navigateur
