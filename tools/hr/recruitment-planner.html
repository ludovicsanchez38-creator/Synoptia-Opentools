Guide d'utilisation

  • Ajouter un candidat : Remplissez le formulaire avec les informations du candidat
  • Pipeline Kanban : Les candidats sont automatiquement placés dans "En attente"
  • Déplacer un candidat : Utilisez les boutons pour faire avancer ou reculer un candidat dans le pipeline
  • Étapes : En attente → Entretien → Offre → Embauché ou Refusé
  • Statistiques : Suivez vos métriques de recrutement en temps réel
  • Export : Exportez tous les candidats au format CSV

Conseils

  • Ajoutez des notes détaillées pour chaque candidat (compétences, impression d'entretien...)
  • Utilisez le champ CV pour stocker un lien vers le CV du candidat
  • Mettez à jour régulièrement le statut des candidats
  • Exportez régulièrement vos données pour garder une trace
