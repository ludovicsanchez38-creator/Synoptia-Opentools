Guide d'utilisation

  • Ajouter une absence : Remplissez le formulaire avec les informations de l'employé et les dates
  • Calendrier visuel : Les jours d'absence sont colorés selon le type (vert = congés, rouge = maladie, bleu = RTT, gris = non justifié)
  • Statistiques : Consultez le nombre total de jours par type d'absence
  • Filtre : Filtrez les absences par employé pour une vue personnalisée
  • Export CSV : Exportez toutes les données pour Excel ou Google Sheets
