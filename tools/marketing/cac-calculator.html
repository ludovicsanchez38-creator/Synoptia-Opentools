Comment utiliser cet outil

Le CAC (Customer Acquisition Cost) représente le coût total pour acquérir un nouveau client.

Formules :

  • CAC = (Coûts Marketing + Coûts de Ventes) / Nombre de nouveaux clients
  • Ratio LTV/CAC = LTV / CAC (idéal : 3:1 à 5:1)
  • Payback Period = CAC / Revenu mensuel moyen (en mois)

Interprétation :

  • CAC faible : Bonne efficacité marketing, mais vérifiez la qualité des clients
  • CAC élevé : Peut être acceptable si le LTV est proportionnellement élevé
  • Ratio LTV/CAC < 3 : Problématique, rentabilité faible
  • Ratio LTV/CAC > 5 : Excellent, opportunité d'investir plus en acquisition
  • Payback < 12 mois : Excellent, récupération rapide de l'investissement

Optimisation :

  • Optimisez vos canaux marketing les plus performants
  • Améliorez le taux de conversion de vos campagnes
  • Automatisez les processus de vente pour réduire les coûts
  • Ciblez mieux vos audiences pour réduire le gaspillage
  • Investissez dans le marketing de contenu et le SEO (CAC plus faible à long terme)
