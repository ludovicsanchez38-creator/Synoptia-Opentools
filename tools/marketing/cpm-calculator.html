Comment utiliser cet outil ?

  1. Entrez le nom de votre campagne
  2. Indiquez le budget publicitaire dépensé
  3. Renseignez le nombre d'impressions générées
  4. Ajoutez les clics pour comparer CPM vs CPC (optionnel)
  5. Analysez votre CPM et le ROI estimé

Formule

CPM = (Budget / Impressions) × 1000 Exemple: 1000€ pour 100 000 impressions CPM = (1000 / 100000) × 1000 = 10€ CPC = Budget / Clics CTR = (Clics / Impressions) × 100

CPM vs CPC - Quand les utiliser ?

  • Utilisez le CPM pour les campagnes de notoriété, branding, et awareness
  • Utilisez le CPC pour les campagnes de performance, conversion, et trafic qualifié
  • CPM moyen : 3€ - 10€ selon les plateformes (Facebook, Google Display, etc.)
  • Un CTR élevé (>1%) rend le CPM plus intéressant que le CPC
