Comment utiliser cet outil

Un test A/B compare deux versions pour déterminer laquelle performe le mieux.

Formules :

  • Taux de conversion = (Conversions / Visiteurs) × 100
  • Différence = Taux B - Taux A
  • Amélioration relative = ((Taux B - Taux A) / Taux A) × 100
  • Test Z pour significativité statistique (niveau de confiance 95%)

Interprétation :

  • Statistiquement significatif : Confiance >95% - Vous pouvez déployer le gagnant
  • Non significatif : Continuez le test ou augmentez l'échantillon
  • Taille d'échantillon : Plus elle est grande, plus les résultats sont fiables
