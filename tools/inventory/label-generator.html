Comment utiliser

  • Code-barres EAN-13 : Code international à 13 chiffres pour l'identification produit
  • Templates : Choisissez le format adapté à vos besoins (standard, compact, large)
  • Quantité : Générez plusieurs étiquettes identiques d'un coup
  • Impression : Utilisez le bouton Imprimer ou Ctrl+P pour imprimer les étiquettes
  • Sauvegarde : Les étiquettes sont enregistrées dans votre navigateur
