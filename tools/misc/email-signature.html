Comment utiliser cette signature

  1. Cliquez sur "Copier HTML" pour copier le code
  2. Ouvrez les paramètres de votre client email (Gmail, Outlook, etc.)
  3. Trouvez la section "Signature"
  4. Activez le mode HTML ou éditeur avancé
  5. Collez le code copié
  6. Sauvegardez votre signature

Note : Certains clients email peuvent nécessiter des ajustements du code HTML.
