Comment utiliser cet outil ?

  1. Sélectionnez le mois concerné
  2. Renseignez les encaissements (ventes, paiements reçus)
  3. Renseignez les décaissements (achats, salaires, charges)
  4. Le solde de trésorerie est calculé automatiquement
  5. Les alertes s'affichent si la trésorerie devient négative

Formules

  • Flux net = Encaissements - Décaissements
  • Solde final = Solde initial + Flux net
  • Alerte rouge : Solde final < 0
  • Alerte orange : Solde final < 10% des encaissements
