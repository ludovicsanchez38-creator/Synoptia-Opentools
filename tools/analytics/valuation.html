Recommandation

Comment utiliser ce calculateur ?

  1. Renseignez vos données financières (CA, EBITDA, actifs)
  2. Ajustez les paramètres de valorisation selon votre secteur
  3. Le calculateur applique 4 méthodes différentes
  4. Consultez la valorisation moyenne et les écarts
  5. Exportez le rapport de valorisation

Méthodes de valorisation

  • DCF : Somme des flux de trésorerie actualisés sur N années
  • Multiple de CA : Chiffre d'affaires × Multiple sectoriel
  • Multiple d'EBITDA : EBITDA × Multiple sectoriel
  • Actifs nets : Valeur comptable des actifs nets
