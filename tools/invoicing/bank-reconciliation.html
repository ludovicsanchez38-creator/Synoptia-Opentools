Comment utiliser cet outil ?

  1. Ajoutez vos écritures comptables dans la colonne de gauche (montant positif = crédit, négatif = débit)
  2. Ajoutez les opérations bancaires dans la colonne de droite
  3. Utilisez le rapprochement automatique ou rapprochez manuellement les opérations correspondantes
  4. Consultez le récapitulatif pour identifier les écarts éventuels
  5. Exportez le rapport pour votre comptabilité

Conseils

  • Les opérations rapprochées apparaissent en vert
  • Les opérations non rapprochées apparaissent en jaune
  • Le rapprochement automatique cherche les montants et dates identiques
  • Un solde équilibré indique que toutes les opérations sont rapprochées
